## 🎮 About the Game

the cabin game is a first-person cooperative horror card game developed and published by Twisted Corridor. It entered Early Access on August 27, 2026, for Windows PC. Designed for one to four players, it combines card-based deduction, procedural cabin construction, exploration, stealth, and survival horror.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **the cabin game**. This trainer provides configurable assistance for the cabin game's card-driven escape loop. It can reduce time pressure, help reveal investigation information, protect players from threats, and simplify exploration while preserving the game's room-building, clue, event, and escape mechanics.

**Target Audience:** Players who want to practice the card system, study player-designed cabin layouts, investigate clues without time pressure, test Event encounters, explore monster behavior, or enjoy a more relaxed solo or private co-op experience.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Freeze Clock** — Stops the shared clock from advancing while players investigate rooms, organize clues, or plan their next card play.
- **Reveal Active Clue** — Displays the currently active investigation clue to make the three-clue escape deduction easier to follow.
- **Infinite Card Draws** — Allows additional card draws without exhausting the available turn resources.
- **Escape Assistance** — Marks the currently valid escape room after the required clues have been revealed.

### 📌 Survival

- **Skip Event Resolution** — compatibility selected Event card sequences that normally interrupt the table phase with hazards, puzzles, or monster encounters.
- **Invulnerability** — Prevents damage and death during exploration and hostile encounters.
- **Disable Monster Pursuit** — Stops active monsters and the Visitor from chasing or catching the player during cabin exploration.

### 🚶 Movement

- **Unlimited Sprint** — Removes stamina limitations during first-person movement and emergency escapes.

### 📌 Exploration

- **Teleport to Built Room** — Moves the player to a selected room that has already been placed in the player-designed cabin.
- **No-Clip Exploration** — Allows players to move through selected cabin obstacles and inspect room layouts without normal collision restrictions.

### 📌 Progression

- **Infinite Candy** — Provides unlimited candy for purchases at the Boo Factory, including cosmetic customization, lobby items, pets, and usable tricks or treats.

## 📖 Detailed Feature Guide

### Movement & Exploration

The cabin game uses first-person movement between the round table and the rooms created by Room cards. Use Unlimited Sprint for faster searches, Disable Monster Pursuit when learning routes, and Teleport to Built Room only after the destination has been created in the current cabin. No-Clip Exploration is best reserved for inspecting blocked corridors or testing room connections.

### Tools & Inventory

The main gameplay inventory is the player's hand of cards, which controls room placement, clues, events, time effects, and other turn actions. Use Infinite Card Draws to study card interactions without exhausting a run. Candy is a separate progression currency used at the Boo Factory for cosmetics, lobby items, pets, and tricks or treats; Infinite Candy affects that currency rather than the active card hand.

### World & Environment

The cabin is assembled during the run according to player decisions, so room placement affects routes, search time, and later event consequences. Build a compact connected layout before enabling exploration assistance. Reveal Active Clue and Freeze Clock can be used to examine the rooms already placed, record environmental evidence, and identify the correct escape room without rushing against the clock.

### Combat & Weapons

The cabin game does not use a conventional weapon-based combat system. Survival depends on evasion, movement, event responses, and avoiding or escaping monsters such as the Visitor and other hostile encounters. Invulnerability and Disable Monster Pursuit are intended for learning these encounters, while Skip Event Resolution can compatibility selected danger sequences.
